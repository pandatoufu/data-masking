# 本地脱敏工具（data-masking）

[中文](README.md) | [English](README.en.md)

> 把文件发给 LLM 之前，在**本机**先脱掉敏感词和机密信息；需要时再用配对 mapping 把回复还原回来。

一个基于 Go + Wails v2 的桌面应用：独立窗口运行，不打开浏览器、不创建业务 TCP 监听、不上传文件。同一套处理核心还可作为 **stdio MCP 子进程**供本地模型客户端调用，并可无界面回归测试。

---

## 功能特性

- **双页单文件流**：`脱敏` 与 `还原` 两个页面，一次处理一个文件。
- **六类内置规则 + 自定义词**：手机号、身份证、email、IP、API Key，以及按字面量精确匹配的自定义词。
- **四档方案**：三档只读预设 `strict` / `balanced` / `minimal`，加一档可自由开关规则的 `custom`。
- **可逆脱敏**：生成方括号占位符与配对明文对照表（mapping），用 LLM 回复中的占位符即可还原。
- **DOCX 保格式处理**：处理正文、表格、页眉页脚、脚注尾注、原生文本框中的文字，保留表格与图片，删除批注并接受支持的修订。
- **多编码容忍**：纯文本自动检出 UTF-8 / GBK；逐行保留 CRLF / LF 原样，不做换行归一化。
- **GUI 自动落盘**：可选，把产物按类型写入程序旁的固定目录；绝不覆盖已有文件。
- **固定目录快捷选择**：脱敏页可从 `original/`、`cards/` 下拉选择直属文件，还原页可从 `pending/`、`mapping/` 选择；需显式选中后才读取，全部手动入口与粘贴仍保留。
- **原生保存与文件保护**：显式另存对话框，源文件、已有文件和符号链接一律不覆盖。
- **失败无半成品**：任一步失败都不产出半成品文件，也不覆盖原件。

## 快速开始（桌面）

### 1. 获取程序

从本仓库的 [Releases](https://github.com/pandatoufu/data-masking/releases) 页面按对应 release 的说明选择 Windows 或 Linux 包。若尚无适用于当前平台的发布包，请按 [从源码构建](docs/development.md) 生成；最终用户运行发布程序不需要安装 Go、Wails 或 Node。

### 2. 放置程序

解压或复制到**用户可写、且不在模型项目目录内**的本地位置，例如：

- Windows：`C:\Tools\data-masking\`
- Linux：`~/opt/data-masking/`（需保留 executable 权限）

程序目录固定为工作区根目录（`os.Executable()` 解析符号链接后的真实目录），不使用启动目录，也没有配置项。目录还需支持**硬链接**（本地 NTFS / ext4 等）；FAT/exFAT 不支持，程序会明确失败并提示另选本地目录。

### 3. 准备运行依赖

- **Windows 10/11 amd64**：系统 **Evergreen WebView2**。缺失或过旧时应用给出原生提示，**经你确认后**才打开微软官方安装页，不会静默安装。
- **Linux（Fedora / Ubuntu）amd64**：**GTK3**、**WebKitGTK 4.1** 以及正常的图形 / session bus 会话；Ubuntu 包名 `libgtk-3-0`、`libwebkit2gtk-4.1-0`，Fedora 为 `gtk3`、`webkit2gtk4.1`。动态库缺失可能在出现任何界面之前就加载失败。

### 4. 脱敏

1. 启动应用，默认进入 `脱敏` 页。
2. **选择文件**（纯文本不限后缀、可无后缀，或 `.docx`），或从 `original/` 下拉菜单选择程序旁的直属文件（需先刷新、选中后才读取）。Windows 支持点击或拖入，Linux 仅支持点击选择。
3. **选择方案**：默认 `balanced`，只处理手机号、API Key 与自定义词，**不处理 email、IP 和身份证号**；需要更严格或更精细时选择 `strict`、`minimal` 或 `custom`。
4. （可选）**填写或导入自定义词**：文本框手输、导入 TXT，或从 `cards/` 下拉选择单个 TXT 词卡；字面量精确匹配、大小写敏感。
5. **执行脱敏**，成功后保留两项产物：
   - 脱敏副本：`<原文件名>.masked.<扩展名>`（无后缀与 `.env` 等点文件回退 `.masked.txt`）
   - 配对 mapping：`<原文件名>.masked.mapping.json`
6. 工作区可用时自动写入 `masked/` 与 `mapping/`，也可分别另存；只保存其中一项时，页面会提示另一项尚未保存。
7. **只把脱敏副本发给 LLM。** `.mapping.json` 含原文对照表，**只留本机，绝不要发给模型或上传任何在线服务**。

### 5. 还原

1. 进入 `还原` 页，从 `pending/` 下拉选择直属文件、用“选择还原文件”手动选择，或直接粘贴回复文本。
2. 选择本机上次保存的**配对 mapping**（`.mapping.json`，可从 `mapping/` 下拉选择或手动选择），务必确认没有拿错。
3. 执行还原并保存结果。

- 还原对占位符做大小写 / 全角 best-effort 匹配；被 LLM 改写或翻译掉的占位符无法找回。
- 未知占位符残留会给出醒目警告（疑似拿错 mapping），但不阻断保存。

完整的格式/预算、规则细节、GUI 操作与目录契约见 [详细使用指南（中文）](docs/usage.md)。

### 可选：本地 MCP 接入

同一程序目录下的 `data-masking-agent`（Windows 为 `data-masking-agent.exe`）可作为**本地 stdio MCP 子进程**，供支持 MCP 的客户端在发送前调用脱敏与还原，提供 `prepare_document`、`confirm_operation`、`restore_document` 三个工具。桌面入门**不需要**安装或配置 MCP 客户端。

接入 JSON、`profile` 选择、cards 词库、两类人工确认、回程幂等与禁读指引见 [MCP 接入与任务参考（中文）](docs/mcp.md)。该指引是**合作式软约束，不是权限隔离**。

## 平台与格式

- **纯文本**：不限后缀，可无后缀，也可使用 `.env`、`.gitignore` 等点文件（后缀比较大小写不敏感）；常见示例有 `txt`、`md`、`csv`、`json`、`yaml`、代码与日志。按顺序判定编码，含 NUL / UTF-16 拒绝，先严格 UTF-8 再严格 GBK，否则拒绝。换行按行保留 CRLF / LF，不做归一化。
- **已知不支持**：`pdf`、`doc`/`docm`、`odt`、`rtf`、`ppt`/`pptx`、`xls`/`xlsx` 等办公文档，`pages`/`numbers`/`key`，以及 `zip`/`7z`/`rar`/`gz` 等容器、`exe`/`dll`/`so` 等程序和 `png`/`jpg`/`gif` 等图片后缀按名称拒绝；即使字节可以解码也不当纯文本处理。请用原程序转换为纯文本或另存为 `.docx`，不建议只改后缀。
- **DOCX**：Transitional / Strict 均可；宏文档、加密、数字签名包拒绝。
- **单文件大小**：默认 10 MiB，可用配置调整；词文件 ≤ 1 MiB，每词 ≤ 256 字符，单次参与词数 ≤ 1000。
- 名称策略是有限的已知格式集合，不是通用格式识别；名称允许也不代表内容已验证。二进制识别只依据 NUL / UTF-16 与严格编码链的启发式，**不承诺识别所有二进制**。纯文本只做字面替换，**不保证代码或 JSON/CSV 等结构化数据替换后的语法有效**。

完整限制与 DOCX 解压预算见 [详细使用指南](docs/usage.md#支持的文件格式与限制)；平台特有行为与构建前提见 [从源码构建](docs/development.md)。

## 安全与使用边界

### 数据与规则

- **mapping 不外发**：配对 `.mapping.json` 含明文原文对照，只用于本机还原。
- 本工具只按规则处理，**不承诺发现未知敏感信息，也不承诺语义级无泄露**；结果应视为“已按规则处理”，而不是“绝对安全”。残留校验只验证规则覆盖率，命中残留会给出定位与计数警告，你可确认后仍导出。
- `balanced` 默认不处理 email、IP 与身份证号；`strict` 只是启用既有六类规则，同样不是安全保证。手机号与身份证规则针对**中国大陆**号码。

### DOCX 处理范围

- 支持处理的文字：**正文、表格、页眉页脚、脚注尾注、Word 原生文本框**；图片与表格结构保留。
- 删除批注、接受支持的修订后，**审阅历史不可恢复**。
- **不在处理范围**：图片中的文字、文档属性、字段指令、数据绑定源、超链接目标、图表 / SmartArt、嵌入附件；**刷新字段或绑定可能重新引入未处理内容**。

### 还原边界

- 占位符匹配是大小写 / 全角 **best-effort**；被模型改写或翻译掉的占位符**无法找回**。
- 还原只恢复 mapping 中的文字，**不恢复审阅历史、原 ZIP 字节或跨 run 混合样式**；文本还原**不恢复 Word 排版**。
- 每个 headless 任务只有一次成功回程；回程告警仅为参考信号，不阻断本地结果。

### 本地运行

- 桌面应用不上传文件、不创建业务 TCP 监听；MCP 入口是本地 stdio 子进程，不把原文或 mapping 交给模型。
- MCP 的安全指引是**合作式软约束**：客户端可能忽略，模型也可能不遵守，不构成权限隔离或 OS 沙箱。
- 自动落盘依赖硬链接，**不覆盖**源文件、已有文件或符号链接；必需目录不可用时 GUI 降级为仅手动另存。
